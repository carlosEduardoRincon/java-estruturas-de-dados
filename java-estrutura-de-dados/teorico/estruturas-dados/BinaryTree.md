### Binary Tree

- Head (Node)
- Left (Node)
- Right (Node)

- Implementação com: LinkedList;

- Formas de percorrer uma binary tree:
- Preorder Traversal:
  - Percorre a esquerda inicialmente e volta percorrendo a direita;
  - Root é o primeiro elemento;
  
- Postorder Traversal:
  - Root no final; 

- Inorder Traversal:
  - Root no meio;
