### Binary Tree

- Head (Node)
- Left (Node)
- Right (Node)

- Implementação com: LinkedList;

- Formas de percorrer uma binary tree:
  - Preorder Traversal:
    - Percorre a esquerda inicialmente e volta percorrendo a direita;
    - Root é o primeiro elemento;
  
  - Postorder Traversal:
    - Root no final; 

  - Inorder Traversal:
    - Root no meio;

- Buscas em binary tree
  - DFS (Deaf First Search/busca em profundidade);
    - Muito semelhante à implementação do preorder traversal;
  - BFS (Breath First Search/busca em amplitude);
